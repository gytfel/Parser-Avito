# Parser-Avito: поиск товаров на перепродажу

Парсер ищет на Авито объявления в выбранной категории и оценивает каждое как сделку на перепродажу:

- **сравнивает с рынком**: собирает аналоги (та же модель, память, конфигурация) с Авито, Юлы и ваших
  CSV с других площадок, отбрасывает выбросы, подделки и «на запчасти»;
- **учитывает дефекты** по тексту объявления: разбитый экран, iCloud, «не включается», АКБ под замену,
  майнинг у видеокарт, царапины, сколы и т.д. Понимает отрицания: «без сколов и царапин», «экран не разбит»;
- **сравнивает характеристики**: ёмкость АКБ, наличие коробки, чека и гарантии против того, что обычно
  есть у аналогов;
- **считает цену продажи и прибыль**: за сколько реально продать, сколько уйдёт на расходы и ремонт,
  итоговый плюс и ROI;
- **предупреждает о рисках**: предоплата, реплика, подозрительно низкая цена.

Результат выводится в терминал и сохраняется в HTML-отчёт: таблицу можно сортировать, у каждого лота
есть расчёт, найденные дефекты с цитатами и ссылки на аналоги.

## Запуск

Нужен Python 3.10 или новее ([python.org](https://www.python.org/downloads/); на Windows при установке
отметьте «Add python.exe to PATH»). Скачайте проект (`git clone https://github.com/gytfel/Parser-Avito.git`
или кнопка Code → Download ZIP) и запустите:

- **Windows** — двойной клик по `start.bat` (или `start.bat` в терминале в папке проекта);
- **macOS / Linux** — в терминале в папке проекта: `./start.sh`.

При первом запуске скрипт сам создаст окружение в папке `.venv` и поставит зависимости (пара минут),
дальше запускается сразу. Откроется меню, где всё выбирается цифрами:

```
=== Поиск товаров на Авито для перепродажи ===
Что сделать?
  1. Найти выгодные объявления для перепродажи
  2. Оценить объявление по ссылке
  3. Следить за новыми объявлениями (проверка каждые N минут)
  4. Демо на вымышленных данных (без интернета)
  5. Выход
Номер [1]:
```

Дальше меню спросит категорию, что искать (Enter — запросы категории по умолчанию), бюджет, город
и минимальную прибыль. Значение в квадратных скобках подставляется, если просто нажать Enter.
Сумму можно писать как `40000`, `40 000` или `40к`. После поиска откроется HTML-отчёт, а меню
покажет команду, которой тот же поиск запускается сразу, без вопросов.

## Запуск командой

Те же действия можно запускать одной командой — удобно, когда параметры уже понятны. Вместо
`start.bat` на macOS/Linux пишите `./start.sh`; если зависимости поставлены вручную
(`pip install -r requirements.txt`), можно и `python -m avito_flip`.

```bash
# Посмотреть, как это работает, на вымышленных данных (без интернета)
start.bat demo --open

# Список категорий и запросов по умолчанию
start.bat categories

# Найти выгодные iPhone 13 в Москве с бюджетом до 40 000 ₽
start.bat scan -c phones -q "iphone 13" --max-price 40000 --open

# Все запросы категории из настроек (iphone 13, iphone 14, ...)
start.bat scan -c phones

# Купить в Москве, оценить рынок ещё и по Петербургу
start.bat scan -c consoles -q "ps5" --market-region sankt-peterburg

# Оценить конкретное объявление по ссылке
start.bat analyze "https://www.avito.ru/moskva/telefony/iphone_13_128_gb_1234567890"

# Следить за новыми объявлениями каждые 15 минут и присылать выгодные в Telegram
start.bat watch -c gpu -q "rtx 3060" --max-price 25000 --every 15 --telegram
```

Если Авито часто блокирует запросы, можно включить загрузку через настоящий браузер (необязательно):

```bash
.venv\Scripts\python -m pip install playwright      # macOS/Linux: .venv/bin/python -m pip install playwright
.venv\Scripts\python -m playwright install chromium # macOS/Linux: .venv/bin/python -m playwright install chromium
start.bat scan -c phones -q "iphone 13" --browser
```

Полезные флаги `scan`:

| Флаг | Что делает |
|---|---|
| `-q "запрос"` | поисковый запрос, можно указать несколько раз |
| `--min-price`, `--max-price` | цена покупки (бюджет); на оценку рынка не влияет |
| `--region moskva` | регион покупки: `moskva`, `sankt-peterburg`, `ekaterinburg`, `all` (вся Россия) |
| `--market-region X` | дополнительный регион для оценки рынка |
| `--pages 5` | сколько страниц выдачи смотреть (~50 объявлений на страницу) |
| `--details 10` | сколько лучших вариантов открыть целиком (полное описание и характеристики) |
| `--min-profit 3000` | от какой прибыли считать «выгодно» |
| `--csv file.csv` | цены с других площадок (см. ниже) |
| `--all` | показать все варианты, а не только выгодные |
| `--html`, `--csv-out`, `--json-out` | куда сохранить отчёт; CSV открывается в Excel |
| `--open` | открыть HTML-отчёт в браузере |
| `--browser`, `--proxy URL` | обход блокировок |
| `-v` | показывать каждый запрос |

## Категории

| Ключ | Категория | Что распознаётся |
|---|---|---|
| `phones` | Смартфоны | iPhone, Samsung Galaxy, Xiaomi/Redmi/POCO, Pixel, Huawei/Honor и др.; память, ОЗУ, АКБ |
| `tablets` | Планшеты | iPad (Air/Pro/mini, чип M), Galaxy Tab, Xiaomi Pad |
| `laptops` | Ноутбуки | MacBook (M1–M5), серии Asus/Lenovo/HP/MSI…; процессор, видеокарта, ОЗУ, SSD |
| `gpu` | Видеокарты | RTX/GTX/RX/Arc, объём видеопамяти; майнинг, артефакты, прогрев |
| `consoles` | Приставки | PS4/PS5 (Slim/Pro, с дисководом/цифровая), Xbox, Switch, Steam Deck |
| `audio` | Наушники, колонки | AirPods, Sony WH/WF-1000XM, Яндекс Станции, JBL, Marshall |
| `watches` | Смарт-часы | Apple Watch (серия, размер), Galaxy Watch |
| `photo`, `any` | Фото, все категории | сравнение по словам заголовка |

Аксессуары («Чехол для iPhone», «Стекло на айфон», «Левый наушник AirPods») и объявления «Куплю»
отсеиваются автоматически. Свою категорию можно добавить в `config.yaml`, пример есть в `config.example.yaml`.

## Как считается выгода

1. **Аналоги.** Из всех найденных объявлений (Авито в нужных регионах, Юла, CSV) берутся те, у которых
   совпадает модель и конфигурация: «iPhone 13 128 ГБ» не сравнивается с «iPhone 13 Pro» или с 256 ГБ.
   Подделки, «на запчасти», объявления с серьёзными дефектами и с предоплатой в рынок не попадают.
   Цены дешевле 45% и дороже 220% медианы, а также выбросы по межквартильному размаху отбрасываются.
2. **Цена продажи** — 40-й процентиль цен аналогов (чуть ниже медианы, чтобы продать за 1–2 недели),
   с поправками:
   - АКБ хуже, чем у аналогов: −0,6% за каждый процент разницы (до −15%); лучше — до +3%;
   - коробка, чек, гарантия, «идеальное состояние» — относительно того, как часто они есть у аналогов;
   - новый/запечатанный, если аналоги б/у: +8%;
   - минус уступка покупателю (`sell_haggle`, 5%).
3. **Дефекты.** Каждый дефект снижает цену при продаже «как есть» (разбитый экран −35%, царапины −4% и т.д.).
   Если дефект ремонтопригоден (экран, АКБ, камера, разъём), считается и вариант «починить и продать».
   Выбирается более выгодный.
4. **Прибыль** = цена продажи − цена покупки (с учётом торга, если продавец его допускает) − расходы
   (`fixed_costs`, `fee_percent`) − ремонт. **ROI** = прибыль / вложения.
5. **Уверенность** зависит от числа аналогов, разброса цен, точности распознавания модели, серьёзности
   дефектов и того, открывалось ли объявление целиком.

Вердикты: ✅ выгодно, ⚠️ выгодно, но есть риск, ➖ маленькая маржа, ❌ невыгодно, 🚫 подделка,
❔ мало данных для оценки.

Все коэффициенты лежат в `avito_flip/default_config.yaml` (экономика) и `avito_flip/defects.py`
(скидки за дефекты). Их стоит подстроить под свою нишу.

## Другие площадки

- **Юла** включена по умолчанию: её объявления участвуют и в оценке рынка, и как кандидаты на покупку
  (купить на Юле дешевле, продать на Авито). Отключить можно флагом `--no-youla`.
- **CSV.** Цены с любых других площадок (Ozon б/у, Яндекс Маркет, барахолки в Telegram, Drom…) можно
  положить в CSV и подключить через `--csv file.csv` или `sources.csv.files` в `config.yaml`:

  ```csv
  title;price;url;description;source;condition
  iPhone 13 128 ГБ;39990;https://...;Отличное состояние;ozon;Б/у
  ```

  Обязательны только `title` и `price`. Русские названия колонок (`название`, `цена`, `площадка`,
  `состояние`) тоже понимаются.

## Настройки

Скопируйте `config.example.yaml` в `config.yaml` и меняйте только нужное. Главное:

- `region`, `market_regions`, `pages` — где и сколько искать;
- `economics.min_profit`, `min_roi`, `fixed_costs`, `fee_percent` — ваша экономика;
- `network.delay_min/max` — пауза между запросами;
- `telegram.token`, `telegram.chat_id` — уведомления для `watch --telegram`.

## Если Авито блокирует

Авито ограничивает частые автоматические запросы (ответ 403/429 или капча). Парсер останавливается
и подсказывает, что делать:

- подождать 15–30 минут: уже скачанные страницы лежат в кэше `.cache/` (1 час) и повторно не загружаются;
- увеличить паузу `network.delay_min/max`;
- установить `curl_cffi` (есть в `requirements.txt`): запросы выглядят как запросы Chrome;
- запустить с `--browser` (Playwright/Chromium);
- указать свой прокси `--proxy` или строку Cookie из браузера в `network.cookies`.

Не ставьте слишком маленькие паузы и много страниц: это нагружает сайт и ведёт к блокировке IP.
Используйте парсер для личного поиска сделок и соблюдайте правила Авито.

## Ограничения

- Дефекты ищутся **по тексту** объявления, фото не анализируются. Продавец может не написать о дефекте,
  поэтому проверяйте товар вживую, IMEI/серийный номер и отвязку от аккаунтов.
- Рынок оценивается по **активным** объявлениям, а не по проданным. Реальные сделки обычно на 5–10% ниже,
  это частично учтено через `sell_quantile` и `sell_haggle`.
- Вёрстка Авито и Юлы меняется. Выдача Авито разбирается двумя способами (встроенный JSON и HTML-карточки),
  поэтому парсер должен пережить небольшие изменения. Если объявлений вдруг стало 0, запустите с `-v` и
  откройте issue.
